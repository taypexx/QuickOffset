# QuickOffset

## About

This mod allows you to quickly change your offset in the custom menu.

![image](https://github.com/user-attachments/assets/372705e5-8669-483a-ac50-93ef6829b423)

To quickly open the list of the offsets press the hotkey ("P" by the default, you can change it in the "Muse Dash/UserData/QuickOffset.cfg")

## Download

Mod uses LocalizeLib v2.2.0 and PopupLib v2.1.1 as dependencies, make sure they are also installed.
[Download here](https://github.com/taypexx/QuickOffset/releases)
